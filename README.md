## GenAI Mindset
Gen IA is not about copy and past. IT's about improving quality and performance of the work. The rule is: `give a prompt, get the response, send other prompts so the response will improve, test it, make changes, and again, and then you are done.`

## Models
- Understand models to select the best model for your needs.
- chatGPT is the most famous but there are many models inside it. Also gemini, meta, anthropic and many many others.
- Try different models and find the best that fit your project's needs.
- `Multimodel` is a concept of model that receives several kinds of files, texts, images.
- Here in this site there are a lot of models: [huggingface](https://huggingface.co/models)
- Not all models are open source.
- There are benchmarks that measure the performance of AI models, such as [artificial analysis](https://artificialanalysis.ai/), [live bench](https://livebench.ai/#/) and [labs scale](https://labs.scale.com/leaderboard)

## Tokens
- Coding consume more tokens.
- Each model can be generating its tokens in different way.
- Tokens are how the ai interprets characters sent to it.
- [can someone explain what exactly is an ai token](https://www.reddit.com/r/NovelAi/comments/nohvse/can_someone_explain_what_exactly_is_an_ai_token/)
- [what are tokens and how to count them](https://help.openai.com/pt-br/articles/4936856-what-are-tokens-and-how-to-count-them)

## Context Windows 
- Keep small conversations
- when in doubt count the tokens in tokenizer
- be aware how many tokens you can send so the model will have space to answer with new tokens.
- ask for conversation summaries to check if the model has the context you need
- Context windows are the "memory" of the model.
- [context window](https://www.ibm.com/think/topics/context-window)
- [Understanding LLM Context Windows: Tokens, Attention, and Challenges](https://medium.com/@tahirbalarabe2/understanding-llm-context-windows-tokens-attention-and-challenges-c98e140f174d)
